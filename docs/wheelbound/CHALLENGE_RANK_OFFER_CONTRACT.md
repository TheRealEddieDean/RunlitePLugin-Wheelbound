## Transparent probability accounting

If Challenge-family probability for a particular slot is q and R ranks are ready/enabled, each rank has unconditional slot probability q/R and conditional rank probability 1/R. For a displayed accepted rank with C eligible creatures and K eligible items on selected creature, assignment odds are 1/C then 1/(C*K). Before card selection the complete path has probability q/(R*C*K); this is a generated-offer path, **not the player's eventual selection probability or an OSRS drop probability**. Multiple slots and player choice affect the distribution of accepted assignments; do not label the per-slot number as run-wide accepted frequency.

For a purely synthetic q=1/4 illustration: one ready rank gets 1/4 slot exposure; two split it 1/8 each; four split it 1/16 each. Total Challenge remains 1/4 in all three examples. The number is not an adopted production weight.
