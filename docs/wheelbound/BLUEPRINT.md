# Blueprint
Start run -> seal one Grand Fate -> build Master Wheel -> assign and complete Fates -> earn FP -> purchase content/modifiers/access -> exhaust finite spins -> Defy or sacrifice -> pursue Grand Fate -> win.

Modes: not started, active, paused, abandoned, won. Assignment substates: idle, rolling/committed, choices pending, ordinary Fate, punishment, forced sacrifice, Grand Fate attempt. Run state and assignment state are separate.

Only one obligation can progress at a time. Pause suspends observation and restrictions freely. Ordinary completion and rejection consume the assignment's one reserved spin exactly once. Grand Fate attempts are between ordinary Fates and use no Master spins. Mandatory punishment/sacrifice blocks ordinary assignments; whether it also blocks Grand Fate is OPEN.

Activity unlock, active slice, card pool unlock and account access are independent permissions. Unlocking a skill does not add its slice. An affordable slice cannot unlock a skill. An assigned quest cannot bypass a locked vendor.
