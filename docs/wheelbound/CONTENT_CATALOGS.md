## Generation and anti-deadlock contract

Evaluate candidates using current account identity, unlocks, real prerequisites, tool/supply acquisition routes, target headroom and detector readiness. Freeze target, reward, scope and catalog version before the Punishment spin. Provisional target duration 30/60/90 minutes, maximum planned 120; these are model assumptions, not time guarantees. XP targets use validated player-rate bands; no forced guess at current skill rate. Resource cost is previewed and must be feasible under current access. Reward remains small and fixed once assigned.

Offer up to twelve distinct eligible templates; if fewer exist, show the actual smaller wheel and explain it. Never duplicate entries to pretend twelve distinct outcomes or enable unsupported restrictions. If no eligible outcome exists, persist a generation error before committing the draw and permit pause; this is a design/runtime defect requiring recovery, not a player penalty. The candidate pool remains frozen through animation/restart; no reroll. This interpretation of roughly twelve outcomes is a new delegated detail.

Escalation changes duration/quantity only within feasible headroom and supply constraints, not forbidden input automation or impossible levels. Completion clears the violation streak by the existing rule; merely pausing does not clear it. Precise escalation coefficients remain balance parameters. A fallback from a committed restricted task to plain XP requires an explicit recovery decision; do not silently relax it.

## Repository boss mapping

The machine-readable source snapshot retains normal-wheel tiers and variants exactly. It is not an approved Wheelbound progression roster. Raids must be grouped into the three confirmed raid nodes in mode progression; the existing normal-wheel tier map puts their modes in different tiers. Do not alter shipped normal behavior or treat Inferno/Colosseum encounters as free Grand Fate access. Review task-only bosses, minigames, keys, entry fees and quest stages before mode assignment. Historical counts are targets, not authority to fabricate encounters.
