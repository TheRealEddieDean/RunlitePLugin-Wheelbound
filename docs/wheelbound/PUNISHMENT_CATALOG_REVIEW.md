## Plain-XP eligibility

These entries add an XP obligation in a named skill without inventing a tool/location restriction. Hitpoints is absent, consistent with its by-product role. A nominal skill unlock is insufficient: validate current game prerequisites, legal accessible resource/tool routes, funds/supplies where actually required, supported initialized XP observations and positive XP headroom. A level-99 skill can still have positive XP headroom; do not substitute level 99 for the actual XP ceiling. Unknown headroom/access is unavailable data, not a verified feasible assignment.

Farming must use a real repeatable route or account for actual timed growth and patch access; a modeled 30-minute quantity is not proof it can be completed in that wall time. Slayer requires an attainable permitted task and actual Slayer XP rather than treating combat XP as Slayer progress. Construction and Herblore need legal supply/access routes. Sailing's presence in the API does not establish a playable task for this account. Prayer requires feasible legal XP sources. Combat permits the assigned combat context and by-products without declaring every simultaneous skill tick defiance.

Freeze objective/quantity/reward and eligibility context before the selected result is displayed. Crash recovery cannot reroll. Paused XP and offline progress cannot backfill. Duplicate XP observations cannot double-count. Unsupported or uninitialized observations cannot trigger a violation. Duration bands and 25 FP rewards remain experiment candidates, not recovered approvals.
